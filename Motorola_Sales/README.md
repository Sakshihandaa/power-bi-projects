# Motorola Sales Analysis

## 📌 Overview
An interactive Power BI dashboard tracking revenue metrics, sales volume, geographical trends and payment method distribution across smartphone sales.

---

## 📊 Key KPIs
* **Total Sales:** 769M
* **Total Quantity Sold:** 19,150 units
* **Total Transactions:** 3,835 orders
* **Average Transaction:** 40,114

---

## 📈 Dashboard Features
* **Geographical Distribution:** Map visualization tracking sales across major Indian cities (Delhi, Mumbai, Bangalore, Hyderabad, etc.).
* **Monthly Trends:** Line chart evaluating unit quantity fluctuations across all 12 months.
* **Customer Feedback:** Funnel chart breaking down 1 to 5-star rating metrics.
* **Payment Channels:** Donut chart analyzing transaction volume across Cash (25.84%), Credit Card (25.48%), Debit Card (24.67%), and UPI (24.01%).
* **Brand & Model Analysis:** Matrix table and bar charts comparing revenue and order count across top brands and mobile models.
* **Daily Patterns:** Area chart monitoring daily sales trends from Monday to Sunday.
